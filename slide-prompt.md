# Prompt: Create Vibe Rise Pitch Deck

Copy everything below this line and paste into Claude Desktop.

Create a beautiful, dark-themed HTML pitch deck with the following specifications. Each slide should be a full-viewport section. Include navigation arrows and keyboard controls (left/right arrows). Make it feel premium, cinematic, and emotional. Not corporate. Not startup-bro. Think Apple keynote meets a TED talk.

## Design Specs

- **Background**: Near-black (#0a0a1a) with subtle gradient shifts per slide
- **Primary accent**: Purple (#5e17eb) → Gold (#E9A23B) gradient (use this for highlights, accent lines, key words)
- **Text**: White (#ffffff) for headers, light gray (#b0b0c0) for body
- **Font**: System sans-serif stack (Inter if available, otherwise -apple-system)
- **Headers**: Large, bold, maximal white space. One idea per slide.
- **Body text**: Short. Under 40 words per slide where possible. Let the visuals and whitespace do the work.
- **No stock photos**. Use typography, whitespace, simple shapes, and the gradient as the visual language.
- **Transitions**: Smooth fade between slides
- **Aspect ratio**: 16:9
- **The 2x2 quadrant graphic**: Should be properly designed with the purple→gold gradient highlighting the "Vibe Rise" quadrant (top right)
- **The flywheel graphic**: Should be a circular diagram, not just text
